# Common Work A — Domain Foundation & Engine — Master Plan

**Roadmap item:** [Common Work A](../00-roadmap.md#common-work-a--domain-foundation--engine) (first post-scaffold block).
**Owning specs:** [02 Domain & Scoring](../../specs/02-Domain-Model-and-Scoring.md) · [03 Ingestion §3.4](../../specs/03-Data-Ingestion-and-PDGA.md#34-event-registration-model) · [04 Leaderboards](../../specs/04-Feature-Leaderboards.md) · [06 OLP](../../specs/06-Feature-OLP-Pot.md) · [10 Admin](../../specs/10-Admin-Console.md) · [12 Architecture](../../specs/12-Architecture.md)
**Stage 1 decisions (this feature):** one PDGA round = one League Night · Podium computed from sub-league standings · current sub-league from admin dates · admin marks sub-league complete · sub-league start/end admin-set · core adjustments (cancel / tag-not-present / pool-switch) included now.
**Stage 2 decisions (this plan):** one pure `computeSeason(input)` → rich result · **whole** engine built now (incl. OLP payout + skins qualification) · read model = **framework + standings only** · **real minimal admin forms** as the data path.

## Goal

Turn the walking skeleton into a foundation that **computes real results from real inputs**: the full domain schema, the complete pure scoring/OLP engine (fixture-verified against the hand calculations), a generalized atomic read-model publish producing the standings proving-view, the shared UI shell every feature will sit in, and thin-but-real admin forms so a director can enter roster / events / entry counts / adjustments and see the published standings change.

This block deliberately does **not** build the four feature views, the real PDGA scraper (Common B), or the full financial ledger (Common C).

## Non-negotiable boundaries (carry through every sub-plan)

- **Engine is pure** — `src/server/engine/` imports no DB, clock, `fetch`, ingestion, or Next.js. `computeSeason(input)` is plain-in → plain-out. Purity is what makes the 81.3 / 81.4 fixtures testable.
- **Public reads never recompute or touch PDGA** — `app/(public)` reads only the published read model.
- **Recompute publishes a new version and flips one pointer in a single SQLite transaction.** Ingestion (Common B) and **admin edits** call the **same** `recompute()`; single-flighted.
- **Server-only stays server-only** — everything under `src/server/` guarded by `import 'server-only'` (except the drizzle-kit-visible `schema.ts`, per the scaffold exception).
- **Season-scoped from day one** — every domain table carries `seasonYear`.
- **Every admin write is audited** (who/what/when/before/after) and triggers recompute ([Spec 10 §10.1](../../specs/10-Admin-Console.md#101-access--audit)).
